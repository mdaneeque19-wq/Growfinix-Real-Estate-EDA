# Growfinix Real Estate Exploratory Data Analysis (EDA)

## Project Overview
This project explores real-estate property data using Python. It analyses property prices, compares neighbourhoods, and examines the relationship between property size and price.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Tasks Completed
- Explored a real-estate dataset.
- Checked for missing values.
- Practised filling missing values using the median.
- Created a bar graph comparing property prices by neighbourhood.
- Created a scatter plot showing property size versus price.
- Detected a potential outlier using the IQR method.
- Generated a statistical summary.

## Sample Results
- Properties analysed: 10
- Neighbourhoods: 3
- Average property price: 75 lakhs
- Minimum property price: 35 lakhs
- Maximum property price: 150 lakhs
- Average property size: 1,130 sq. ft.
- Potential outliers detected: 1

## Conclusion
This project demonstrates basic data cleaning, exploratory data analysis, and data visualisation using Python.

## Dataset Note
The current project uses synthetic sample data created for practice. The results do not represent verified real-estate market prices.
